# Cyber Secrity

## Research & Learn 
Common cyber security threats when working remotely include phishing, malware, weak passwords, unsecure networks and lack of multi-factor authentication.

TO keep devices and accounts secure, one must use multi-factor authentication on all logins, set strong and unique passwords, regular updates and using trusted networks. Also, I should keep my computer on lock whenever I step away to prevent any unauthorised access.

I should avoid clicking suspicious links or opening unexpected attachmeents to handle phishing attempts. If I recieve a suspicious message, I should verify the sender and report it through the appropriate channel.

Strong passwords should be long, unique and difficult to guess. A password manager makes it easier to use unique passwords without having to remember all of them.

2FA provides an additional layer of security even if a password is compromised, so I should enable it wherever possible.

## Reflection
I already use passwords and multi-factor authentication, but I can improve by making sure all my important logins has MFA configured and being more diligent when handling any mails to avoid phising.

I can make security a habit by building simple checks into my daily routine, such as locking my computer and checking links before opening them.

I will use strong, unique passwords and a password manager where appropriate, and enable 2FA on important accounts

If I suspect a security breach, I will secure the affected account, change or revokee compromised credentials if appropriate, and report the incident immediately.

## Task
I will always lock my computer when stepping away and verify suspicious links or messages before interacting with them. I will also enable 2FA on work accounts wherever possible.
