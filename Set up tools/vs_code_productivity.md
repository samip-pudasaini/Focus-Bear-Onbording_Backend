# VS code Setup

## Shortcuts

### Navigation

- Quick Open files: Ctrl + P
- Go to Definition: F12 (Jumps to source of a function or variable)
- Toggle Sidebar: Ctrl + B

### Editing

- Select Next Occurrence (Muti-Cursor): Ctrl + D
- Manual Muti-Cursor: Alt + click
- Column Multi-Cursor: Ctrl + Alt + Up/Down (spawns cursorsvertically up/down
  for column-based editing)
- Move Line Up/Down: Alt + Up/Down (Swaps the current line with the line above
  or below it.)
- Toggle Line Comment: Ctrl + / (Instantly comments out or uncomments the
  selected line of code)

### Debugging

- Toogle Breakpoint: F9 (Adds or removes a debugging pause point on the current
  line.
- Start/Continue Debugging: F5 (Launches your applicat ion in debug mode or
  resumes execution)
- Step Over: F10 (Executes the next line of code without diving into functions)

### Terminal

- Toggle Integrated Terminal: Ctrl + `

## Reflection

### Which shortcuts will help me most daily?

The shortcuts I will use most often are Ctrl + P, Ctrl + D, Alt + Up/Down, and
Ctrl + /. Ctrl + P will help me quickly navigate between files without manually
searching through the project structure. Ctrl + D with multi-cursor will speed up
renaming variables, Alt + Up/Down will allow me to reorganize code quickly.

### How will shortcuts improve my productivity?

Using keyboard shortcuts will reduce the amount of time I spend switching between
the keyboard and mouse and navigating through menus. This will make common tasks
such as opening files, editing and debugging much faster.
